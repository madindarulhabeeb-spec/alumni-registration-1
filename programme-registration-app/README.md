# 🚀 Programme Registration Portal

A complete, modern web application for registering event/competition participants with separate Participant and Host views, dynamic topic/song selection, disclaimer notice, host spreadsheet dashboard, and one-click link sharing.

---

## 📁 Folder Structure

```
programme-registration-app/
├── index.html            # Main web application entry point (Participant & Host views)
├── styles.css            # Responsive CSS stylesheet & spreadsheet table styling
├── app.js                # Form logic, dynamic topic/song fields & database handlers
├── firebase-config.js    # Firebase Cloud Database configuration template
├── vercel.json           # Vercel deployment & URL rewrite configuration
├── firebase.json         # Firebase Hosting deployment configuration
├── .gitignore            # Git ignore configuration
├── server.ps1            # Standalone Windows PowerShell HTTP web server (optional)
└── README.md             # Complete setup & deployment guide
```

## ⚡ Quick Start (Local Testing)

### Method 1: Local Server (Windows PowerShell)
1. Open PowerShell in this project folder:
   ```powershell
   cd C:\Users\User\.gemini\antigravity\scratch\programme-registration-app
   ```
2. Start the local server:
   ```powershell
   .\server.ps1
   ```
3. Open in browser:
   - **Host Dashboard**: `http://localhost:8080/host`
   - **Participant Registration**: `http://localhost:8080/register`

## 🌐 Deploying to GitHub, Firebase, & Vercel

To make your registration link accessible to participants anywhere on the internet with live real-time sync, follow these steps:

### 1. 🔥 Step 1: Set Up Firebase Cloud Database (Real-time Sync Across Internet)

1. Go to [Firebase Console](https://console.firebase.google.com/) and click **Add Project**.
2. Give your project a name (e.g., `programme-registration`) and click **Create Project**.
3. In the project dashboard, click the **Web icon (`</>`)** to add a Web App.
4. Copy the `firebaseConfig` object provided by Firebase.
5. Open `firebase-config.js` in your editor and replace the placeholder keys:
   ```javascript
   const firebaseConfig = {
     apiKey: "AIzaSy...",
     authDomain: "programme-registration.firebaseapp.com",
     projectId: "programme-registration",
     storageBucket: "programme-registration.appspot.com",
     messagingSenderId: "123456789",
     appId: "1:123456789:web:abcdef"
   };
   ```
6. In Firebase Console sidebar, go to **Build > Firestore Database** -> Click **Create Database**.
7. Choose **Start in test mode** and select your location -> Click **Enable**.

Now, whenever any participant anywhere in the world registers, their submission instantly saves to Firebase and appears live on the Host Dashboard!

---

### 2. 🐙 Step 2: Upload Project to GitHub

1. Go to [GitHub.com](https://github.com/) and click **New Repository**.
2. Name your repository (e.g., `programme-registration-app`) and click **Create Repository**.
3. Upload your project folder to GitHub using one of these methods:
   - **GitHub Web Upload**: Click **Upload an existing file** on GitHub, drag and drop all files from `programme-registration-app/`, and click **Commit changes**.
   - **GitHub Desktop**: Download [GitHub Desktop](https://desktop.github.com/), choose *Add Local Repository*, select `programme-registration-app`, and click **Publish repository**.

---

### 3. 🔺 Step 3: Deploy to Vercel (1-Click Deployment)

1. Go to [Vercel.com](https://vercel.com/) and log in (or sign up with GitHub).
2. Click **Add New > Project**.
3. Import your GitHub repository (`programme-registration-app`).
4. Keep framework setting as **Other / Standalone** and click **Deploy**.
5. Once deployed, Vercel will give you a live public URL (e.g. `https://programme-registration.vercel.app`)!

#### Live Links Generated by Vercel:
- **Host Link**: `https://your-app.vercel.app/host`
- **Participant Link**: `https://your-app.vercel.app/register`

> Inside the **Host Link**, click **Copy Link** to share `https://your-app.vercel.app/register` with your participants!

---

### 4. 🪟 Step 4 (Optional): Deploy to Firebase Hosting

If you want to host on Firebase Hosting instead of Vercel:
1. Install Firebase CLI: `npm install -g firebase-tools`
2. Run `firebase login`
3. Run `firebase init hosting`
4. Run `firebase deploy`
